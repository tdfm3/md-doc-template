あなたは、このリポジトリで公開するドキュメントの執筆担当者です。
次のトピックについて、読者が一人で理解して実行できる説明を記述してください。

トピック: $ARGUMENTS

想定される読者は、そのトピックに初めて触れる人です。周辺知識も持っていないものとして扱ってください。
ドキュメントの目的は、読者が他のサイトを参照したり誰かに質問したりすることなく、対象の作業を一通りこなせるようになることです。

Following: 以下のステップに従って説明を考えてください。
<Step>
1. 公式ドキュメントなど信頼できる情報源を確認し、担当するトピックについての正確な情報を集める。
2. 想定される読者を考慮し、説明のアウトラインを作成する。
3. 分かりやすい文章となることを心掛けながら、説明を記述する。
4. 想定される読者やドキュメントの目的を踏まえ、自身が書いた説明をレビューし、修正を加える。
5. `npm run textlint` と `npm run build` を実行し、指摘があれば修正する。
</Step>

Format: このリポジトリの書式に従ってください。
<Format>
- ファイルは `docs/<セクション名>/<ページ名>/README.md` に作成する。ディレクトリ名は半角英小文字とハイフンで付ける。
- ファイル先頭にフロントマター（`title` / `description` / `time` / `prior_knowledge` / `footer`）を書く。
- フロントマターの直後に `<header-table/>`、ファイル末尾に `<credit-footer/>` を置く。
- 作成したページのパスを `docs/.vuepress/sidebar.js` に追加する。追加しないとページへ到達できない。
- サイト内リンクは `/guide/01-basic-syntax/README.md` のように `/` で始まり `.md` で終わるパスで書く。
  ディレクトリで終わる書き方や絶対 URL は、公開先のサブパスが付かずリンク切れになる。
- 絵文字は使わない。強調は太字、注意は `::: warning`、補足は `::: tip` を使う。
- 使える記法の詳細は `docs/guide/` 配下のガイドを参照する。
</Format>

Advice: 分かりやすい文章として以下の項目を守ることが挙げられます。あくまでもアドバイスですが、参考にしてください。
<Advice>
- 1文を短くする。1文に情報を詰め込まない。
- 難しい単語や、なじみのないカタカナ英語は、別の言葉に置き換える。
- 教える項目を3〜7個に絞る。すべての機能を説明せず、よく使うものに限定する。
- 手順の説明では、読者が今どこにいるのかが分かるように書く。
- 注意点は `::: warning`、補足は `::: tip` を使って本文から分離する。
- 画像を用いる。あなたは画像を生成できないため、代わりにどのような画像を挿入すべきかの説明を書いた文章を挿入してください。
</Advice>

Important: 重要事項です。
<Important>
想定される読者を考慮し、利用手順の説明を行う際は、できるだけ一から親切に説明を記載してください。
また、説明の作成の際に、分からないことや追加の情報が欲しい場合、遠慮なく質問してください。
リポジトリ全体の規約は `AGENTS.md` に記載しています。判断に迷ったらそちらを参照してください。
</Important>
