# Markdown の基本記法

Markdown は、**記号を使って文章に意味をつける書き方**です。
`# 見出し` のように書くと、表示するときに見出しとして整形されます。

この章で説明するのは、GitHub でも Qiita でも通用する標準的な記法だけです。
このテンプレート固有の記法は[次の章](/guide/02-vuepress-syntax/README.md)で説明します。

[[toc]]

## 見出し

行の先頭に `#` を付けると見出しになります。`#` の数が見出しの深さです。

**書き方:**

```markdown
# 大見出し
## 中見出し
### 小見出し
#### さらに小さい見出し
```

**ポイント:**

- `#` と文字の間には半角スペースを入れる
- `#` 1つはページタイトル用なので、1ページに1つだけにする
- 深さを飛ばさない（`##` の次に `####` を書かない）
- `##` と `###` の見出しは、ページ右側の目次に自動で並ぶ

## 段落と改行

空行で区切ると段落になります。

**書き方:**

```markdown
これは1つめの段落です。

これは2つめの段落です。
```

**注意が必要なのは、段落の中で改行したい場合です。**
単に改行しただけでは、表示するときにつながってしまいます。

**書き方:**

```markdown
行末に半角スペースを2つ入れると、  
ここで改行されます。
```

**表示結果:**

行末に半角スペースを2つ入れると、  
ここで改行されます。

## 強調

文字を目立たせる記法です。

**書き方:**

```markdown
**太字にしたい文字**
*斜体にしたい文字*
~~打ち消したい文字~~
```

**表示結果:**

**太字にしたい文字**
*斜体にしたい文字*
~~打ち消したい文字~~

**ポイント:**

- 記号と文字の間にスペースを入れない（`** 太字 **` は効かない）
- 日本語では斜体が読みにくいため、強調は太字を使う

## リスト

### 箇条書き

行頭に `-` を付けます。

**書き方:**

```markdown
- りんご
- みかん
- ぶどう
```

**表示結果:**

- りんご
- みかん
- ぶどう

### 番号付きリスト

行頭に `1.` のように数字とピリオドを付けます。

**書き方:**

```markdown
1. 手順の1つめ
2. 手順の2つめ
3. 手順の3つめ
```

**表示結果:**

1. 手順の1つめ
2. 手順の2つめ
3. 手順の3つめ

::: tip 番号は全部 1. でもかまいません
表示するときに自動で連番になります。途中に項目を挿入しても番号を振り直さずに済みます。
:::

### 入れ子にする

半角スペース2つまたは4つ分インデントすると、入れ子になります。

**書き方:**

```markdown
1. 大項目1
   - 小項目1-1
   - 小項目1-2
2. 大項目2
   - 小項目2-1
```

**表示結果:**

1. 大項目1
   - 小項目1-1
   - 小項目1-2
2. 大項目2
   - 小項目2-1

## リンク

**書き方:**

```markdown
[表示するテキスト](https://example.com)
```

**サイト内の別ページへのリンクは、`/` から始まり `.md` で終わるパスで書きます。**

```markdown
[フロントマターの説明](/guide/03-frontmatter/README.md)
```

**表示結果:**

[フロントマターの説明](/guide/03-frontmatter/README.md)

::: warning 末尾の `.md` を省略しないでください
VuePress が公開先に合わせてリンクを書き換えるのは、**`.md` で終わる内部リンクだけ**です。
`/guide/03-frontmatter/` のようにディレクトリで終わる書き方は外部リンクとして扱われ、
サブディレクトリで公開したときにリンク切れになります。

| 書き方 | 結果 |
|------|------|
| `/guide/03-frontmatter/README.md` | 正しく解決される |
| `/guide/03-frontmatter/` | リンク切れになる |
| `https://...` の絶対 URL | 公開先が変わると切れる |
:::

## 画像

書き方はリンクとほぼ同じで、先頭に `!` を付けます。
角カッコの中には、画像が表示できなかったときに出る説明文（代替テキスト）を書きます。

### そのページ専用の画像

ページと同じディレクトリに `images/` を作って置き、`./` から始まるパスで参照します。

**書き方:**

```markdown
![折れ線グラフのサンプル](./images/sample.svg)
```

**表示結果:**

![折れ線グラフのサンプル](./images/sample.svg)

### サイト全体で使う画像

ロゴのように複数ページから使う画像は `docs/.vuepress/public/` に置き、`/` から始まるパスで参照します。

**書き方:**

```markdown
![サイトのロゴ](/hero.svg)
```

どちらを使うかの判断は、[4. 執筆から公開までの流れ](/guide/04-workflow/README.md)で説明します。

## 引用

行頭に `>` を付けます。他の資料から文章を引用するときに使います。

**書き方:**

```markdown
> 引用したい文章をここに書きます。
> 複数行にもできます。
```

**表示結果:**

> 引用したい文章をここに書きます。
> 複数行にもできます。

## コード

### 文中のコード

文章の中で少しだけコードを示す場合は、バッククォート（`` ` ``）で囲みます。

**書き方:**

```markdown
設定は `config.js` に書きます。
```

**表示結果:**

設定は `config.js` に書きます。

### 複数行のコード

バッククォート3つ（` ``` `）で囲みます。開始側のバッククォートの直後に言語名を書くと、
色分け（シンタックスハイライト）されます。

**書き方:**

````markdown
```javascript
function hello() {
  console.log('Hello World');
}
```
````

**表示結果:**

```javascript
function hello() {
  console.log('Hello World');
}
```

**よく使う言語名:**

| 言語名 | 対象 |
|------|------|
| `javascript` / `typescript` | JavaScript / TypeScript |
| `csharp` | C# |
| `python` | Python |
| `json` / `yaml` | 設定ファイル |
| `bash` / `powershell` | コマンド |
| `markdown` | Markdown そのもの |
| `text` | 色分けしたくないとき |

::: tip コードブロックの中にコードブロックを書きたいとき
この章のように「書き方」を見せたい場合は、外側をバッククォート4つ（` ```` `）で囲みます。
:::

## 表

縦棒（`|`）とハイフン（`-`）で作ります。

**書き方:**

```markdown
| 列1 | 列2 | 列3 |
|------|------|------|
| データ1 | データ2 | データ3 |
| データ4 | データ5 | データ6 |
```

**表示結果:**

| 列1 | 列2 | 列3 |
|------|------|------|
| データ1 | データ2 | データ3 |
| データ4 | データ5 | データ6 |

**ポイント:**

- 1行目が見出し行になる
- 2行目の `---` が見出しとデータを区切る
- 縦棒の位置は揃っていなくてもよい

### 文字の配置を変える

2行目にコロン（`:`）を足すと配置が変わります。

**書き方:**

```markdown
| 左寄せ | 中央寄せ | 右寄せ |
|:------|:------:|------:|
| 左 | 中央 | 右 |
```

**表示結果:**

| 左寄せ | 中央寄せ | 右寄せ |
|:------|:------:|------:|
| 左 | 中央 | 右 |

## 水平線

ハイフン3つ以上を単独の行に書くと区切り線になります。

**書き方:**

```markdown
---
```

::: danger ページ先頭では使わないでください
ページの先頭で `---` を書くと、フロントマター（ページの設定）と解釈されます。
詳しくは[3. フロントマターとコンポーネント](/guide/03-frontmatter/README.md)を参照してください。
:::

## 記号をそのまま表示する

`*` や `#` をそのまま表示したい場合は、直前に `\` を付けます。

**書き方:**

```markdown
\*これは斜体になりません\*。
```

**表示結果:**

\*これは斜体になりません\*。
