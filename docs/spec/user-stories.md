# ユーザーストーリー

::: tip これはひな形です
`〇〇` の部分を自分のプロジェクトの内容に書き換えて使ってください。
:::

## 書き方

ユーザーストーリーは「誰が、何をしたくて、それはなぜか」の形で書きます。

```text
〇〇（利用者）として、
〇〇（したいこと）をしたい。
なぜなら〇〇（理由・得られる価値）だからだ。
```

機能ではなく**利用者の目的**を書くのが要点です。
「検索ボックスを付ける」ではなく「探している記述にすぐたどり着きたい」と書きます。

| US-001 | 〇〇 | 〇〇 | 〇〇 | 高 |
| US-002 | 〇〇 | 〇〇 | 〇〇 | 中 |
| US-003 | 〇〇 | 〇〇 | 〇〇 | 低 |

## 受け入れ条件

各ストーリーが「完成した」と判断できる条件を書きます。

### US-001

- [ ] 〇〇ができる
- [ ] 〇〇の場合でも〇〇になる
- [ ] 〇〇が記録される
