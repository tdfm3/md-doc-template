## 書きはじめるためのひな形

中身は空のテンプレートです。**自分のプロジェクトの内容に書き換えて使ってください。**

| 文書 | 何を書くか | いつ書くか |
|------|------|------|
| [アーキテクチャ決定記録（ADR）](/spec/adr.md) | 技術選定の理由と、検討した代替案 | 重要な技術判断をしたとき |
| [プロダクト要求仕様書（PRD）](/spec/prd.md) | 何を、誰のために、なぜ作るのか | プロジェクトの立ち上げ時 |
| [ユーザーストーリー](/spec/user-stories.md) | 利用者視点でやりたいことの一覧 | 作るものを分解するとき |
